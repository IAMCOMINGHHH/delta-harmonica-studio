# 三角洲口琴工坊

一个零依赖、离线优先的《三角洲行动》口琴学习、制谱与 Windows 自动演奏项目：提供键位说明、虚拟演奏、数字简谱解析、本地曲库、试听，以及用户主动启用的键鼠自动演奏器。

> **重要：** `desktop_player.py` 会通过 Windows `SendInput` 模拟键盘和鼠标输入。三角洲行动官方明确禁止能模拟按键的自动脚本、硬件宏和鼠标宏；使用本功能可能导致账号或设备封禁。本项目不提供反检测、绕过 ACE、注入游戏或读取游戏内存的能力。

## 功能

- 点击虚拟按键或使用 `Z X C V B N M ,` 在网页内吹奏
- 输入数字简谱，自动生成音名和游戏手动键位提示
- 浏览器 Web Audio 试听、速度调节和逐音高亮
- 内置公版/传统旋律示例；自建曲库存入浏览器 `localStorage`
- 曲库 JSON 导入与导出，不上传任何用户数据
- 响应式界面，可直接部署到 GitHub Pages
- Windows 桌面演奏器：选曲、三秒倒计时、全局热键、暂停和紧急停止

## Windows 游戏内自动演奏

要求 Windows 10/11 与 Python 3.10+。双击：

```text
启动自动演奏器.bat
```

也可在终端运行：

```powershell
python desktop_player.py
```

操作流程：

1. 在桌面演奏器中选歌或输入简谱，设置 BPM。
2. 游戏中拿出口琴，确保输入法为英文状态。
3. 按 `F6`，在三秒倒计时内切回游戏。
4. `F7` 暂停/继续，`F8` 立即停止并释放所有按键。

默认启用“跳过长休止”：正常换气保留，超过两拍的伴奏空白会压缩到两拍。需要严格照原谱等待时可取消勾选。

网页导出的 `delta-harmonica-library.json` 可以直接由桌面演奏器导入。若游戏以管理员身份运行，桌面演奏器也可能需要相同权限才能发送输入。

自动演奏仅使用 Win32 `SendInput` 和 `RegisterHotKey`；不打开游戏进程、不访问内存、不使用驱动、不联网。它仍属于官方明令禁止的自动输入行为，技术实现简单不代表账号安全。

## 运行

直接双击 `index.html`，或在项目目录运行：

```powershell
npm run serve
```

然后打开终端显示的本地地址。自动测试：

```powershell
npm test
```

## 简谱格式

| 写法 | 含义 |
| --- | --- |
| `1`–`7` | 中音自然音 |
| `1,` / `1'` | 低八度 / 高八度 |
| `#4` | 升半音 |
| `0` | 休止一拍 |
| `0/2` / `0*2` | 休止半拍 / 两拍 |
| `-` | 前一个音延长一拍 |
| `3/2` | 半拍 |
| `3*2` | 两拍 |
| `3/2~` | 半拍，并与下一音近似连奏 |
| `|` | 小节线（仅排版） |

示例：`1 2 3 4 | 5 6 7 1' | 0 #5 4 3 | 2 - 1 -`

## 默认游戏映射（需自行校对）

| 功能 | 默认操作 |
| --- | --- |
| 自然音 `1 2 3 4 5 6 7 1'` | `Z X C V B N M ,` |
| 低八度 | 按住鼠标左键 |
| 升半音 | 按住鼠标中键 |
| 高八度 | 按住鼠标右键 |

该映射来自社区项目的实测说明，游戏版本或玩家设置可能变化，请以游戏内界面为准。
